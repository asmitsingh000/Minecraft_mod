# Pixle_Lucia
Expand your Minecraft world with new resources, equipment, nature, and building possibilities.

Pixle Lucia is a custom Minecraft Java Edition mod built with Fabric. It introduces new ores, armor, tree types, exclusive decorative blocks, and a unique Chisel tool designed for building.

Originally developed as a quest for Lucia in Hack Club's Pixl, this project is also available for anyone who wants to explore and experience its additions to Minecraft.

## Features

Pixle Lucia introduces new content to make exploration, equipment progression, and building more interesting.

## Custom Ores

Discover additional ore types and expand the resources available in your Minecraft world.

## New Armor

Craft and equip custom armor introduced by the mod.

## New Tree Types

Explore new varieties of trees that add more diversity to the Minecraft environment.

## Exclusive Blocks

Experiment with unique blocks designed to give your builds a different appearance.

## The Chisel

Get access to a dedicated Chisel tool created for building and working with the mod's exclusive blocks.

## Project Background

Pixle Lucia was developed as part of a quest assigned by Lucia on Pixl.

The objective was to create a Minecraft mod that introduces custom content and gives players something new to discover and use in their worlds.

What started as a quest became a playable Fabric mod that others can download, explore, and enjoy.

# Installation & Download

## Requirments

Component
- Minecraft Java Edition   26.1.2
- Fabric Loader            0.19.2
- Fabric API               0.155.3+26.1.2
- Java                     25

## How to Install

1. Install Minecraft Java Edition version 26.1.2.

2. Install the matching Fabric Loader.

3. Install the matching Fabric API.

4. Download the Pixle Lucia .jar file from the release link above.

5. Press Win + R, enter %appdata%\.minecraft, and open the mods folder.

6. Place the downloaded .jar file inside the mods folder.

7. Launch Minecraft using your Fabric installation.
